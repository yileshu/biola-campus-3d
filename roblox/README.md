# Biola Campus — Roblox version

A native Roblox place of Biola University's campus, built only from open data:

| Layer | Source | Licence |
|---|---|---|
| Building footprints, names, walkways, roads, parking, fields, surrounding streets and houses | OpenStreetMap | ODbL — "© OpenStreetMap contributors" (shown in-game) |
| Terrain, building heights, flat vs pitched roofs, tree positions/heights | USGS 3DEP lidar (`CA_LosAngeles_1_B23`) | Public domain |
| Facades, roofs, trees, lamps, benches | Generated by `Tools/roblox/build_roblox.py` | This project |

**No Google content.** Google Photorealistic 3D Tiles may only be streamed inside our own app, so
they are not (and must not be) used for the Roblox place.

## Get the place

* Download **BiolaCampus.rbxl** from the [`roblox-latest` release](../../releases/tag/roblox-latest)
  (rebuilt by the *Build Roblox place* workflow on every relevant push), or from that workflow's artifact.
* Open it in **Roblox Studio** (File ▸ Open from File).

## First time in Studio

1. **Bake the terrain** (once): View ▸ Command Bar, run

   ```lua
   require(game.ServerStorage.BiolaTerrain).Build()
   ```

   It takes ~30–90 s and writes ~6.8 M voxels (grass with 3D grass blades, asphalt roads and
   parking, pavement sidewalks, brick walkways, sand, water). Then **File ▸ Save**.
   If you skip this, `ServerScriptService/BuildTerrain` builds the terrain when a server starts.
2. Check **Lighting**: Technology = *Future*, ClockTime 15.5, Atmosphere / Bloom / SunRays /
   ColorCorrection are pre-configured. Press **Play**.
3. In game: walk around, **N** toggles day / night (street lamps and ~40 % of windows light up).
   Building names float above named buildings.
4. To publish: File ▸ Publish to Roblox. Keep the in-game attribution label.

## What is in the place

* 53 campus buildings (22 detailed "hero" buildings with entrances, rooftop units, the Library
  beacon) — walls in Plaster / Brick / Concrete, glass windows with sills, floor bands, parapets with
  coping, clay-tile hip/gable roofs where the lidar shows pitched roofs.
* ~450 houses and apartments along the streets around campus (OSM footprints, simple hip roofs).
* ~900 trees at their real lidar positions (palms, oaks, jacarandas), ~320 street lamps with
  PointLights, benches.
* Scale: **1 stud = 0.3 m**. +X = east, −Z = north. Spawn at the Biola Ave. entrance.
* ≈ 33 k parts. If Studio feels slow, delete `Workspace/Campus/Neighborhood` or enable
  Workspace ▸ StreamingEnabled.

## Regenerate / edit with Rojo

```bash
pip install numpy pillow
```

```bash
python3 Tools/roblox/build_roblox.py --preview
```

```bash
rojo build roblox/default.project.json -o BiolaCampus.rbxl
```

`rojo serve roblox/default.project.json` live-syncs into Studio. Styles (colours, materials,
window sizes) are in `STYLES` in `Tools/roblox/build_roblox.py`; per-building style choice in
`style_for`. `--preview` writes rough software renders to `roblox/preview/` (geometry check only —
Roblox's lighting and materials look much better).
